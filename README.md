A Machine Learning project that classifies news articles as **Fake or Real** using Natural Language Processing (NLP) techniques. The system is deployed as a web application for real-time prediction.

---

## 🌍 Live Demo
👉 (https://fake-news-detector-1plp.onrender.com/)

---

## 🚀 Tech Stack
- Python
- Pandas
- Scikit-learn
- NLTK
- Flask (for web app)

---

## ✨ Features
- Detects fake vs real news articles
- Uses NLP preprocessing (tokenization, stopword removal, stemming)
- TF-IDF for feature extraction
- Logistic Regression & Naive Bayes models
- Displays prediction with confidence score
- Interactive web interface using Flask

---

## 📊 Model Performance
- Logistic Regression Accuracy: 98.8%
- Naive Bayes Accuracy:  93.37%
- Feature Extraction: TF-IDF

---

## 🔄 Workflow
1. Data Collection (Fake & Real news dataset)
2. Text Preprocessing (Cleaning, Stopwords Removal, Stemming)
3. Feature Extraction using TF-IDF
4. Model Training (Logistic Regression, Naive Bayes)
5. Model Evaluation (Accuracy, Confusion Matrix)
6. Deployment using Flask
